# JJ's BirdBuster

<img src="public/assets/page/banner.png" alt="JJ's BirdBuster (Preview)" width="600" />

A short pixel-art autorunner. Web, phone-landscape first, playable on a computer; about a quarter of an hour. Built with Phaser 4, Vite and TypeScript.
